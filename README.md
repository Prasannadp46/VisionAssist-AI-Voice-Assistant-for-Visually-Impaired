# VisionAssist AI

VisionAssist AI is a voice-guided accessibility assistant designed to help visually impaired users interact with their environment.

## Features

* **Real-Time AI Vision:** Captures images and describes surroundings aloud using smart visual recognition.
* **Hands-Free Voice Control:** Enables seamless navigation through instant voice commands and audio feedback.

## Getting Started

### Run Application
```bash
python app.py
```
Open `http://localhost:5000` in your browser.
